# 报告插图清单

答辩/提交前把以下图片放入本目录，并在 `课程设计报告.md` 对应位置替换占位。

| 文件 | 内容 | 来源 |
|---|---|---|
| `system.jpg` | 整机正面/背面/工作状态 | 实物拍摄 |
| `block.png` | 系统总体框图 | 可用 draw.io/立创EDA 绘制 |
| `power.png` | 电源树 | draw.io/立创EDA |
| `wiring.png` | Pi/STM32/外设接线图 | draw.io/立创EDA/手绘拍照 |
| `schematic.png` | 扩展板/系统原理图 | 立创EDA |
| `sim-uart.png` | UART 时序仿真 | Proteus |
| `sim-pwm.png` | PWM 占空比仿真 | Proteus/示波器 |
| `flow-main.png` | 系统主流程图 | draw.io |
| `flow-cmd.png` | 命令解析流程图 | draw.io |
| `ui-chat.png` | Web 聊天界面截图 | 浏览器截图 1440×900 |
| `ui-device.png` | 设备控制面板截图 | 浏览器截图 |
| `led.jpg` | LED 控制实物 | 实拍 |
| `lcd.jpg` | LCD 显示 Hello | 实拍 |
| `adc.png` | ADC 读数截图 | 串口/前端截图 |
| `pwm.png` | PA2 PWM 波形/电压 | 示波器/万用表照片 |

## 要求

- 图幅能放入 A4，字号 ≥8pt；截图不要拉伸变形。
- 仿真图注明工具、版本、模型；实测图注明日期与条件。
- 报告图注写清“图 X …”，正文引用。
