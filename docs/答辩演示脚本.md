# 答辩演示脚本（3–5 分钟）

## 演示前 10 分钟检查

```bash
# 1) 服务与模型
curl -sS http://127.0.0.1:8080/health
curl -sS http://127.0.0.1:8081/health
curl -sS http://127.0.0.1:8000/api/device/status

# 2) 串口
curl -sS http://127.0.0.1:8000/api/device/ping

# 3) 浏览器
# 打开 http://<树莓派IP>:8000/，Ctrl+F5 强制刷新
```

- 若 VCP 写阻塞：拔插一次开发板 USB，等 3 秒，刷新页面。
- 若后台未启动：`ROOT=$HOME/ai-terminal bash scripts/start_all.sh`。
- 备用：`paper/答辩PPT.pptx` 内有截图的备份页面。
- 云端模型为可选演示：需要有效 Key，现场网络不通时直接讲本地模式。

## 演示台词与操作

### 1. 开场（20 秒）

“本项目在树莓派 4B 上本地运行 Qwen2.5-1.5B 和 SmolVLM-500M，通过 Web 聊天界面把自然语言转换成 STM32G431 的硬件动作；默认完全离线，也可以选配云端大模型。”

展示 PPT 第 1–3 页（题目、背景、架构）。

### 2. 板卡知识问答（35 秒）

在聊天框输入：

> LED 的数据口是哪几个引脚？

预期：秒级返回 `PC8–PC15`、`PD2` 锁存和低电平点亮，不贴无关代码。

再输入：

> 定时器的引脚有哪些？

预期：直接给 `PWM1=PA2（TIM15_CH1）`、`PWM2=PA3（TIM15_CH2）`，并说明其它定时器没有固定接板载外设。

### 3. 输入历史（15 秒）

在输入框按 **↑**：

预期：召回上一条问题；再按 **↓** 回到当前草稿。说明：多行输入时只在首/末行触发，不会影响光标移动。

### 4. 自然语言控制 LED（30 秒）

输入：

> 让 LED1 亮起来。

预期：界面显示“已执行 `LED 1 1` → OK LED 1 1”，开发板 LED1 点亮；再输入“关掉 LED1”。

### 5. 代码讲解页（50 秒）

点击右侧 LED“开/关”，页面自动切到“代码讲解”：

- 顶部“本次操作代码”显示本次灯号、操作前后位图和 `LED_Disp()` 参数；
- 下方是时钟 → 引脚 → 锁存 → main 的完整代码；
- 点“复制”可复制完整代码。

再点 LCD“显示”，代码里的字符串会同步变成实际输入文本。

### 6. ADC 与 PWM（40 秒）

面板读取 ADC1(PB12)/ADC2(PB15)，转动电位器数值变化；代码讲解中的采样通道和值同步变化。

面板设置 PWM1(PA2)=20%、PWM2(PA3)=40%，应用后回读一致；PA2/PA3 输出 1kHz，万用表可测平均电压（如有示波器可展示波形）。

### 7. VLM 图片问答（40 秒，选做）

点击图片按钮，上传一张图片，输入：

> 请描述这张图片。

预期：约 30–40 秒后返回描述（演示图可用红圆+HELLO 测试图）。说明：VLM 为单图低频推理，不做实时摄像头。

### 8. 云端模型（30 秒，选做）

点顶栏“云”：

- 接口类型：OpenAI 兼容（DeepSeek/OpenAI）或 Anthropic 兼容（MiniMax/Claude）；
- 填 Base URL、模型名、Key，选择思考强度（低/中/高）；
- 测试连接成功后保存并启用。

预期：顶栏变为“云端 · 模型 · 强度”；此后除硬件命令外所有问答走云端，并附带板卡事实卡 + 知识库检索结果。演示后点“停用”，Key 从页面内存清除。

### 9. 收尾（30 秒）

展示 PPT 第 8–10 页：

- 硬件命令、1.5B LLM、VLM、代码讲解、输入历史全部实测；
- 30 分钟稳定性数据（见 `stability_summary.json`）；
- 不足与改进：VCP 9600、1.5B 开放问题 40–120s、VLM 速度、无摄像头；
- 云端模型为可选增强，Key 只存页面内存，不写入项目文件；
- 总结：完成端侧多模态 AI + 硬件控制 + 知识库助教的完整闭环。

## 备用方案

| 故障 | 处理 |
|---|---|
| 串口无响应 | 拔插开发板 USB；刷新页面；检查 `/api/device/status` |
| LLM 无响应 | 检查 8080 日志；`bash scripts/run_llama.sh` |
| 1.5B 回答慢 | 改用板卡/引脚/命令快捷问题，走毫秒级直答 |
| 云端失败 | 检查 Base URL/接口类型/Key/额度；直接切回本地 1.5B 演示 |
| VLM 超时 | 先演示 LLM/硬件；VLM 作为选做，说明 34s 延迟 |
| 网络/浏览器问题 | 用报告中的界面布局示意与验证记录讲解 |
| 投影分辨率低 | 浏览器 1280×800；PPT 使用深色大字 |
