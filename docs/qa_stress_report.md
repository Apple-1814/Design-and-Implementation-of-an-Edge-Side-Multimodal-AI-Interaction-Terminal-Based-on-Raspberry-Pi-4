## 3. 发现并修复的问题

1. **记忆问题被直答误判**  
   “我刚才让你记住的数字”被 BM25 命中“回答口径”，返回板卡资料而不是 7319。  
   修复：记忆/上下文类问题绕过直答，从真实对话历史取数字/上一问；实测 `mode=memory`，0.01s。

2. **“代码是什么”被上一轮 LED 检索污染**  
   短问题自动拼接上一轮查询，导致 LED 对话后问代码定义返回 LED 资料。  
   修复：定义类问题不再拼接历史，也不注入 RAG；实测 3.4s 返回通用定义。

3. **多轮代码示例串模块**  
   “LED 在哪 → 那 PWM 呢”会附上 LED 代码。  
   修复：代码示例按当前问题模块选择；`focus` 优先当前模块，只有“那代码呢”才回退上一模块。

4. **源码片段压过板卡事实**  
   LED/USART 引脚题有时只返回 `bsp_led.c`/`bsp_usart.c`，没有 PC8/PA9。  
   修复：直答额外纳入板卡事实候选，并按模块匹配排序；引脚别名（PC8/PA9/PB12…）纳入模块识别。

5. **跨模块问题只答一个模块**  
   “LED 和 USART1 分别用哪些引脚”只返回 USART。  
   修复：检测到多个模块时最多返回两个板卡小节；实测同时包含 PC8/PD2 与 PA9/PA10。

6. **知识缺口**  
   补充了 UART 命令速查、ST-Link/SWD 说明、MCU/主频/Flash/RAM、ADC 软件滤波、RTC 配置小节；重新构建索引至 **1610 片段**。

7. **“下降沿是什么”复读且概念错误**  
   小模型反复输出同一句，还把边沿解释错。  
   修复：为上升沿/下降沿/双边沿/边沿检测增加确定性词条；新增“什么叫 X”“X 的含义”“解释一下 X”等问法识别，全部 0.01–0.05s 返回。

8. **“X 和 Y 的区别”缺路由**  
   对比题落到模型，出现“下降沿=低到高”这类反向错误。  
   修复：识别“X 和 Y 的区别/有什么不同”，分别查词条并合并回答；实测 6/6。

9. **未收录术语被拒绝回答**  
   最初为避免幻觉，未收录术语会回复“暂未收录”，不符合“什么都能解释”的要求。  
   修复：未收录的定义交给 **Qwen2.5-1.5B** 解释，并保留去复读/去泄漏/去假引用清洗；实测“什么是傅里叶变换”返回频率域解释。

10. **小模型复读、泄漏提示词、编造引用**  
   模型会重复整句、回显“[300 字以内, 代码用 Markdown]”、在没有资料时标 [1][2]。  
   修复：生成后统一清洗：全局重复句去除、提示词片段过滤、无来源引用删除、半截句截断；SSE 改为清洗后一次性返回。

11. **“解释一下 ADC”被硬件命令拦截**  
   工具路由把“解释/含义”误判为读取 ADC，返回“ADC 原始值”。  
   修复：工具路由排除解释、含义、定义、指什么、什么叫等问法；读取命令仍正常。

12. **板卡限定词被通用词条截胡**  
   “第二路 ADC 的引脚”“RTC 时钟源”“ADC 查询命令”“PWM 设置命令”被通用 ADC/RTC/PWM 词条回答。  
   修复：含引脚、命令、时钟源、第 N 路、配置等限定词时，通用词条让位给板卡事实卡。

13. **记忆数字被板卡型号污染**  
   助手上一轮回答含 `STM32G431RBT6`，记忆题取到 `431` 而不是用户说的 `7319`。  
   修复：只从用户消息取数字，并用边界排除 G431/PC8 等标识符；首次“请记住 7319”直接确认。

14. **“定时器的引脚有哪些”贴代码/PPT**  
   板卡事实没有命中“定时器”，回答退化成 `bsp_tim.c` 和 TIM PPT 摘录。  
   修复：新增引脚直答表（LED/按键/USART/I2C/ADC/PWM/定时器/SWD/LCD/RTC），引脚题只给引脚清单；多模块问题合并，追问“那 PWM 呢”只答当前模块。

15. **事实题返回整个模块或代码**  
   “板子有几个 LED”“ADC 查询命令是什么”“板子主控芯片是什么”会返回整节资料。  
   修复：新增事实直答层，直接给 8 个 LED、`ADC?`、STM32G431RBT6、0x50、9600 等；数量/命令/型号/地址/频率/供电/尺寸题不再贴代码。

16. **0.5B 知识面不足**  
   升级为 **Qwen2.5-1.5B-Instruct Q4_K_M**（1.07GB），实测 3.02 tok/s；开放问题能解释傅里叶、PID、四季等通用问题。  
   代价：开放问题约 40–120s；引脚/事实/概念题仍是毫秒级直答，不受影响。

## 4. 剩余限制

- 1.5B 仍小于云端大模型，开放问题可能不够深入；事实类走确定性直答，不受影响。
- 开放问题约 40–120s；页面显示等待秒数。引脚/事实/概念/对比题 0.01–0.05s。
- 图片型真题/OneNote 未 OCR。
- 历史会话保存在浏览器 `localStorage`，不同电脑不共享。
- 云端模型可选，依赖网络/Key/额度；不同厂商的模型名、接口协议和参数存在差异。
