# 跨网访问（Cloudflare 临时隧道）

> 当前链接是**临时**的 `*.trycloudflare.com`，适合课堂演示；Cloudflare 不保证长期在线。
> 不要在未加密码的情况下把 8000 端口直接暴露到公网。

## 1. 原理

```text
同学电脑（任意网络）
   │ HTTPS
   ▼
Cloudflare 边缘
   │ 隧道（cloudflared 主动外连，无需公网 IP）
   ▼
树莓派 127.0.0.1:8000（FastAPI）
```

- 树莓派主动连 Cloudflare，不需要路由器端口映射/公网 IP。
- FastAPI 只监听本机回环，由 cloudflared 转发。
- 公网请求带 `CF-Connecting-IP`/`CF-Ray` 头，后端只对这类请求要求 Basic 密码；局域网访问不受影响。

## 2. 访问密码

密码文件在树莓派用户目录，**不提交到 Git**：

```bash
cat ~/.ai_terminal_access
# 格式：用户名:密码
```

修改密码：

```bash
printf 'admin:%s\n' "$(python3 -c 'import secrets; print(secrets.token_urlsafe(12))')" \
  > ~/.ai_terminal_access
chmod 600 ~/.ai_terminal_access
sudo systemctl restart ai-terminal.service   # 或 kill 后由 systemd 拉起
```

浏览器打开公网链接时会弹出登录框，输入文件中的用户名/密码。

## 3. 启动 / 停止隧道

```bash
# 启动（后台运行，输出 URL）
bash scripts/start_tunnel.sh

# 查看 URL 与日志
grep -oE 'https://[a-z0-9-]+\.trycloudflare\.com' ~/ai-terminal/logs/cloudflared.log | tail -1

# 停止
bash scripts/stop_tunnel.sh
```

首次使用需要把 `cloudflared-linux-arm64` 放到 `~/ai-terminal/bin/cloudflared` 并 `chmod +x`。

## 4. 验证

```bash
U="https://<随机名>.trycloudflare.com"
curl -I "$U/"                       # 401（要求密码）
curl -I -u 'admin:<密码>' "$U/"     # 200
curl -u 'admin:<密码>' "$U/api/device/status"
```

SSE 聊天同样走隧道：

```bash
curl -N -u 'admin:<密码>' -H 'Content-Type: application/json' \
  -d '{"messages":[{"role":"user","content":"LED怎么点亮？"}]}' \
  "$U/api/chat"
```

## 5. 安全边界

- 公网链接会暴露聊天、知识库、**LED/ADC/PWM 硬件控制**；必须保留 Basic 密码。
- 不要把密码写进 Git、截图或公开群聊；课堂演示后可停隧道并轮换密码。
- 临时隧道无可用性保证；正式展示建议提前 10 分钟启动并自测。
- 如需长期稳定访问，改用 Cloudflare Named Tunnel + Access，或 Tailscale 虚拟局域网。
