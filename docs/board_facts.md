# CT117E-M4 板卡事实卡（本机实测 + 官方手册）

> 本文件是蓝桥杯嵌入式 AI 助教的“权威底稿”。回答板卡问题时优先依据本文件；
> 与教程冲突时，以本文件中的实测结论和官方 `CT117E-M4 产品手册` 为准。

## 0. 蓝桥杯大赛与竞赛板

- “蓝桥杯”全国软件和信息技术专业人才大赛由工信部人才交流中心主办，电子类包含“嵌入式设计与开发”科目，分省赛和国赛。
- 嵌入式赛道使用 **CT117E-M4（STM32G431RBT6）** 竞赛板；比赛现场提供 Keil、CubeMX 和底层驱动资源包，选手按题目完成外设配置与功能实现。
- 常见题型：LED、按键、LCD、USART、ADC、PWM、I2C/EEPROM、RTC、定时器输入捕获，以及 C 语言/数电/模电/STM32 客观题。
- 备赛路线：先搭“时钟 + LED + 串口”最小工程，再按模块刷题，最后限时做整套省赛/国赛真题。

## 1. 平台身份

- 竞赛平台：**CT117E-M4 嵌入式竞赛实训平台**（北京国信长天）。
- 主控：**STM32G431RBT6**，LQFP64，ARM Cortex-M4F，128KB Flash，32KB SRAM，最高 80MHz。
- 开发环境：Keil MDK V5（竞赛推荐）+ STM32CubeMX；HAL 库；板载 **CMSIS-DAP** 调试器（SWD）。
- 板载 DAPLink 同时提供 USB 转串口，默认连接到 **USART1（PA9/PA10）**。
- 供电：USB 5V；调试/下载使用 CN2（USB Type-B），USB 设备接口为 CN5。

## 3. 已验证引脚与配置

### 3.1 LED（8 位，低电平点亮）

- 数据口：**PC8–PC15**；锁存：**PD2**。
- 位映射：`ucled` 的 bit0→PC8（LD1），bit1→PC9（LD2），……，bit7→PC15（LD8）。
- 极性：**低电平点亮**。`LED_Disp()` 先把 PC8–PC15 全部拉高（全灭），再对需要点亮的位写 0，然后 PD2 产生一个上升沿锁存。
- 初始化：PC8–PC15 推挽输出，默认输出高（全灭）；PD2 推挽输出，默认低。
- 易错点：只写 PC8–PC15 不翻转 PD2，LED 不会更新；PD2 是锁存脉冲，不是使能电平。

### 3.2 按键（按下为低）

| 按键 | 引脚 | `Key_Scan()` 返回值 |
|---|---|---|
| KEY1 | PB0 | 1 |
| KEY2 | PB1 | 2 |
| KEY3 | PB2 | 3 |
| KEY4 | PA0 | 4 |

- 输入模式，代码中 `GPIO_NOPULL`；板上已有外部上拉，按下读到 `GPIO_PIN_RESET`。
- 竞赛程序必须自己做消抖（10–20ms）和“松手检测”，不要在中断里长时间延时。

### 3.3 ADC（电位器）

- 已验证：**PB12 = ADC1_IN11**，12 位，单次转换，软件触发。
- 采样时间：`ADC_SAMPLETIME_640CYCLES_5`；时钟 `SYSCLK` 2 分频。
- 读取流程：`HAL_ADC_Start()` → `HAL_ADC_PollForConversion(..., 10)` → `HAL_ADC_GetValue()` → `HAL_ADC_Stop()`。
- 返回值 0–4095，对应 0–3.3V（参考 VREF+）。
- 产品手册中 J11/J12 还引出 PB15/PB12 电位器分压；本机验证以 **PB12** 为准。

### 3.4 PWM（TIM15_CH1）

- 已验证：**PA2 = TIM15_CH1**；PA3 = TIM15_CH2（同一 TIM15，可选）。
- 时钟 80MHz；`Prescaler=79` → 1MHz 计数；`Period=999` → **1kHz**。
- 占空比：`Pulse = duty * 10`，duty=0–100 对应 0–1000；`PWM_SetDuty()` 已做 100 上限保护。
- 输出模式：PWM1，高电平有效；PA2 复用 `GPIO_AF9_TIM15`，`GPIO_MODE_AF_PP`。
- 易错点：只初始化 TIM 而不 `HAL_TIM_PWM_Start()`，PA2 没有波形；改频率要同时改 PSC/ARR。

### 3.5 USART1（板载 DAPLink 虚拟串口）

- **PA9 = USART1_TX，PA10 = USART1_RX**，复用 `GPIO_AF7_USART1`。
- GPIO 必须配置为 **`GPIO_MODE_AF_PP` 推挽**；官方旧例程若用 `AF_OD` 开漏，主机可能收不到数据。
- 本机 DAPLink VCP 实测：**9600 8N1 稳定**；用 `stty` 改 115200 会阻塞，不等于 MCU 不支持 115200。
- 若需要 115200，建议外接 USB-TTL（CH340/CP2102）到 PA9/PA10，或直接用板载 DAPLink 的固定 VCP 速率。
- 中断接收建议：`HAL_UART_Receive_IT(&huart1, &byte, 1)`，在 `HAL_UART_RxCpltCallback()` 里把字节放入环形缓冲，主循环解析；不要在中断里做 `printf` 或长延时。
- 发送字符串用 `strlen()`，不要用 `sizeof(str)`（会把结尾 `\0` 也发出去）。

### 3.6 I2C / AT24C02

- 常见官方例程：**PB6 = I2C1_SCL，PB7 = I2C1_SDA**，开漏复用，外部上拉。
- AT24C02 7 位地址通常为 `0x50`（写地址 0xA0，读地址 0xA1）。
- 竞赛中优先使用官方 `i2c.c` / `24c02.c` 驱动；注意页写跨页要拆分，写后需要 5ms 左右的内部写周期。
- 若用软件 I2C，必须保证 SCL/SDA 开漏输出并外加上拉，不能推挽强拉。

### 3.7 LCD

- 2.4 寸 TFT，板载并口；官方资源包提供 `lcd.c`、`lcd.h` 和字库。
- 初始化顺序：GPIO/并口初始化 → `LCD_Init()` → `LCD_Clear()` → 设置颜色/背景 → 显示字符串。
- 常见问题：
  - 只调用 `LCD_Init()` 不 `LCD_Clear()`，屏幕可能是花屏/残留；
  - 在定时器中断里刷屏会导致闪烁或卡死，显示放在主循环；
  - 不要套用 F103 的 FSMC 写法，G431 板载 LCD 是 GPIO 并口驱动；
  - 显示中文要使用官方字库/取模，不能直接传 UTF-8 字节。

## 4. 时钟与工程模板

- 外部晶振 HSE = 24MHz；PLL：M=3，N=20，P=2 → **80MHz**。
- AHB/APB1/APB2 均为 80MHz；TIM 时钟 80MHz。
- CubeMX 工程：`ProjectManager.TargetToolchain=MDK-ARM V5`，HAL 包 `STM32Cube FW_G4 V1.6.1`。
- Keil 下载配置：CMSIS-DAP Debugger，SW 模式，Flash Download 勾选 `Reset and Run`。
- 竞赛模板建议：先建一个能编译、能下载、能串口打印的最小工程，再逐个加模块；不要一开始把所有外设都打开。

## 5. 竞赛常用模块清单

1. GPIO：LED、按键、蜂鸣器/继电器。
2. USART：中断接收、环形缓冲、协议解析。
3. LCD：字符串、数值、变量显示。
4. I2C：AT24C02 读写。
5. ADC：电位器采样、滤波、电压换算。
6. TIM：基本定时、PWM 输出、输入捕获/频率测量。
7. RTC：日历/时钟、秒中断。
8. 客观题：C 语言、数电、模电、STM32 基础知识。

## 6. 新手最短上手路径

1. 装 Keil MDK V5 + STM32G4 器件包；装 CubeMX。
2. 用 CubeMX 选 STM32G431RBTx，开 HSE 24MHz，配 80MHz 时钟。
3. 先只配 LED 的 PC8–PC15 + PD2，生成 Keil 工程，编译下载，确认 LD1–LD8 能亮灭。
4. 加按键 PB0/PB1/PB2/PA0，做 10ms 消抖，按键控制 LED。
5. 加 USART1 PA9/PA10（AF_PP），9600 8N1，能收发 `PING`/`OK`。
6. 加 ADC1_IN11 PB12，串口打印电位器值。
7. 加 TIM15_CH1 PA2 PWM，占空比 0/50/100%。
8. 加 LCD，先清屏再显示固定字符串，最后显示变量。
9. 加 I2C1 PB6/PB7 + AT24C02，读写一个字节并回读验证。
10. 最后做真题：先读题划功能，再列外设/引脚，再写状态机，最后联调。

## 7. 调试顺序（非常重要）

1. **先供电和下载**：Keil 能识别 CMSIS-DAP，能擦除/下载。
2. **再时钟**：确认 `SystemClock_Config()` 后系统时钟 80MHz。
3. **再 GPIO**：用万用表/ LED 验证单脚输出。
4. **再串口**：TX 必须推挽；先发固定字符串，确认波特率/接线。
5. **再中断**：NVIC 优先级分组、使能中断、回调函数名必须完全正确。
6. **最后联调**：每个模块单独通过后再组合，避免“一改全乱”。

## 8. 常见故障速查

| 现象 | 优先检查 |
|---|---|
| Keil 找不到下载器 | CMSIS-DAP 驱动、SWD 跳线 J6/J7/J8、USB 线 |
| 下载成功但不运行 | Flash Download 是否勾选 Reset and Run；BOOT0/复位 |
| 串口收不到 | PA9/PA10 是否 AF_PP；TX/RX 是否交叉；波特率；DAPLink VCP 是否 9600 |
| LED 不亮/常亮 | PC8–PC15 极性（低亮）；PD2 是否产生上升沿；是否共地 |
| 按键乱跳 | 是否消抖；是否用外部上拉；是否在中断里长延时 |
| ADC 不变 | PB12 是否模拟模式；是否 `HAL_ADC_Start`；电位器跳线 J12 |
| PWM 无波形 | PA2 是否 AF9；是否 `HAL_TIM_PWM_Start`；PSC/ARR |
| LCD 花屏 | 是否 `LCD_Clear`；并口引脚/时序；是否用官方驱动 |
| I2C 读写失败 | PB6/PB7 是否开漏+上拉；地址 0x50；写周期延时 |
| 程序跑飞 | 栈溢出、数组越界、中断优先级/回调名、未初始化指针 |

## 10. 备赛与真题（省赛/国赛）

- 省赛常见组合：**LED + 按键 + LCD + USART + ADC + PWM**，再加 I2C/EEPROM、TIM 输入捕获、RTC 中的 1–2 个。
- 国赛更强调综合：多模块联动、状态机、串口协议、定时器/PWM 测量、EEPROM 参数保存、LCD 多界面。
- 客观题常考：C 语言（指针/数组/位运算）、数电（逻辑门/时序）、模电（运放/二极管）、STM32 基础（GPIO/中断/时钟/ADC/PWM/I2C）。
- 备赛顺序：先做“最小可下载模板”（时钟 + LED + 串口），再按模块刷题，最后限时做整套真题。
- 考场策略：读题先列“输入/输出/外设/通信/显示”，再画主流程和中断流程；每个模块先单独验证，再联调；留 10 分钟演示与检查。
- 真题资料：省赛/国赛真题汇编在知识库中以目录和截图形式存在；文本检索优先命中本事实卡与模块源码，具体题面请查原 PDF/Word。

## 11. 回答口径

- 先给结论，再给“为什么”，最后给可执行的步骤/代码要点。
- 涉及引脚、时钟、寄存器配置时，明确写出“本板已验证”的事实；不确定的写“以官方资源包/原理图为准”，不要编造。
- 用户问代码时，优先给 HAL 初始化顺序 + 关键函数 + 易错点，不贴与问题无关的整段工程。
- 用户问竞赛策略时，按“读题 → 列外设 → 画流程 → 分模块 → 联调 → 留演示时间”回答。
