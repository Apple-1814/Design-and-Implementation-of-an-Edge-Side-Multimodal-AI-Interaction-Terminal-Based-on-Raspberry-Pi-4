# 课堂演示网络与开机自启

## 1. 拓扑

```text
手机（热点 / USB 共享）
   │ Wi-Fi 或 USB
   ▼
电脑（上网走手机；以太网口只连树莓派）
   │ 网线
   ▼
树莓派 4B（eth0 固定 192.168.49.50）
   │ USB
   ▼
STM32G431（板载 CMSIS-DAP + VCP）
```

- 手机只负责给**电脑**提供互联网；课堂演示的 AI 推理与硬件控制全部在本地，**树莓派不需要联网**。
- 树莓派与电脑之间用固定 IP，避免 DHCP 变化导致网页地址失效。
- 树莓派开机自动启动 LLM / VLM / FastAPI，并在 LCD 显示 `192.168.49.50` 与 `READY`。

## 2. 固定 IP

| 设备 | 网口 | IP | 掩码 | 网关 |
|---|---|---|---|---|
| 电脑 | 以太网 | `192.168.49.11` | `255.255.255.0` | 留空 |
| 树莓派 | eth0 | `192.168.49.50` | `255.255.255.0` | 留空（或走 wlan0） |

> 电脑的互联网走 Wi-Fi/USB 共享，**不要**在以太网口上开启 ICS/Internet 共享，否则以太网 IP 可能被改成 `192.168.137.1`，与树莓派固定 IP 不通。

## 3. Windows 设置（只需一次）

1. `Win + R` → 输入 `ncpa.cpl` → 回车。
2. 右键“以太网” → 属性 → “Internet 协议版本 4 (TCP/IPv4)” → 属性。
3. 选择“使用下面的 IP 地址”：
   - IP 地址：`192.168.49.11`
   - 子网掩码：`255.255.255.0`
   - 默认网关：留空
   - DNS：留空
4. 确定。Wi-Fi/USB 共享保持自动获取，不要改。
5. 验证：

```bat
ping 192.168.49.50
```

浏览器访问：

```text
http://192.168.49.50:8000/
```

## 4. 树莓派自启状态

已安装并启用：

| 服务 | 作用 | 端口 |
|---|---|---|
| `llama.service` | Qwen2.5-0.5B LLM | 127.0.0.1:8080 |
| `vlm.service` | SmolVLM-500M VLM | 127.0.0.1:8081 |
| `ai-terminal.service` | FastAPI + 持久串口 | 0.0.0.0:8000 |

检查命令：

```bash
systemctl is-enabled llama.service vlm.service ai-terminal.service
systemctl is-active  llama.service vlm.service ai-terminal.service
curl http://127.0.0.1:8000/api/device/status
```

实测：开机后约 **22 秒** API 上线；LCD 显示 `192.168.49.50` / `READY`。

## 5. 课堂操作

1. 插好树莓派电源、开发板 USB、网线；电脑连手机热点/Wi-Fi。
2. 打开树莓派电源，等待 LCD 出现 `192.168.49.50` / `READY`（约 20–30 秒）。
3. 电脑浏览器打开 `http://192.168.49.50:8000/`。
4. 按 `docs/答辩演示脚本.md` 演示。

不需要在电脑或树莓派上手动启动任何服务。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 网页打不开 | 电脑 `ping 192.168.49.50`；检查以太网是否为 `192.168.49.11/24`、网关留空 |
| 电脑无法上网 | 手机热点/USB 共享是否开启；是否误把以太网设成 ICS |
| 手机热点地址与 VMware 冲突 | 若热点是 `192.168.43.x`，临时禁用 VMware VMnet10，避免路由抢占 |
| 页面打开但串口未连接 | 拔插开发板 USB；刷新页面；或 `POST /api/device/reconnect` |
| 服务未启动 | `sudo systemctl restart llama.service vlm.service ai-terminal.service` |
| 需要重新安装自启 | `ROOT=/home/apple/ai-terminal bash scripts/install_services.sh` |

## 7. 可选：树莓派也走手机热点上网

演示不需要；如需更新软件/下载模型：

```bash
nmcli device wifi list
nmcli device wifi connect "手机热点名称" password "密码"
```

eth0 仍保持 `192.168.49.50` 固定地址，电脑访问不受影响。
