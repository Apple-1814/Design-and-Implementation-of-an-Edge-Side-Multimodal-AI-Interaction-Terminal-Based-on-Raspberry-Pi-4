# 课堂演示网络与开机自启

## 1. 拓扑

```text
其他同学的电脑 ──Wi-Fi──┐
                        ├── OpenWrt Wi-Fi（192.168.1.0/24）
你的电脑 ───────Wi-Fi───┘
   │ 网线（可选，维护用）
   ▼
树莓派 4B
   ├─ wlan0：192.168.1.165（OpenWrt，其他电脑走这里）
   └─ eth0 ：192.168.49.50（直连你的电脑，维护/烧录用）
   │ USB
   ▼
STM32G431（板载 CMSIS-DAP + VCP）
```

- **其他电脑访问**：连同一个 OpenWrt Wi-Fi，打开 `http://192.168.1.165:8000/`。
- **你的电脑**：走 Wi-Fi 用 `http://192.168.1.165:8000/`，走网线用 `http://192.168.49.50:8000/`，两者都可用。
- AI 推理与硬件控制默认全部在树莓派本地；外网只用于 Wi-Fi 互联，不依赖云端 API。可选云端模型需要外网，Key 只存浏览器页面内存。
- 面板右侧会显示“其他电脑访问：http://…:8000/”，LCD 也显示当前 Wi-Fi IP。

## 2. IP 地址

| 设备 | 网口 | IP | 说明 |
|---|---|---|---|
| 树莓派 | wlan0 | `192.168.1.165` | OpenWrt DHCP；其他电脑访问用这个 |
| 树莓派 | eth0 | `192.168.49.50` | 直连你的电脑，维护/烧录 |
| 你的电脑 | WLAN | `192.168.1.243` | 与树莓派同一 Wi-Fi |
| 你的电脑 | 以太网 | `192.168.49.11` | 与树莓派直连 |

> Wi-Fi IP 由 OpenWrt DHCP 分配，可能变化；以面板“其他电脑访问”或 LCD 显示为准。若希望固定，可在 OpenWrt 里给树莓派 MAC 做静态租约。

## 3. 其他电脑访问（推荐）

1. 其他电脑连接与树莓派**同一个 OpenWrt Wi-Fi**。
2. 浏览器打开：

```text
http://192.168.1.165:8000/
```

3. 不需要安装任何软件，也不需要经过你的电脑。
4. 页面右侧“其他电脑访问”会显示当前实际地址；如果 Wi-Fi IP 变化，以该地址为准。
5. 验证：在同一 Wi-Fi 的电脑上 `ping 192.168.1.165`，再打开上面的 URL。

> 如果其他电脑在不同网络（例如各自手机热点），默认无法互访；需要路由器端口映射或内网穿透，且应先加访问认证，避免把硬件控制接口暴露到公网。

## 4. 你的电脑以太网设置（可选）

1. `Win + R` → 输入 `ncpa.cpl` → 回车。
2. 右键“以太网” → 属性 → “Internet 协议版本 4 (TCP/IPv4)” → 属性。
3. 选择“使用下面的 IP 地址”：
   - IP 地址：`192.168.49.11`
   - 子网掩码：`255.255.255.0`
   - 默认网关：留空
   - DNS：留空
4. 确定。Wi-Fi/USB 共享保持自动获取，不要改。
5. 验证：

```bat
ping 192.168.49.50
```

浏览器访问：

```text
http://192.168.49.50:8000/
```

## 5. 树莓派自启状态

已安装并启用：

| 服务 | 作用 | 端口 |
|---|---|---|
| `llama.service` | Qwen2.5-1.5B LLM | 127.0.0.1:8080 |
| `vlm.service` | SmolVLM-500M VLM | 127.0.0.1:8081 |
| `ai-terminal.service` | FastAPI + 持久串口 | 0.0.0.0:8000 |

- 云端模型为可选：需要 Pi 能访问对应 API 域名（OpenAI/Anthropic 兼容）；课堂无外网时仍可用本地 1.5B。API Key 只存浏览器页面内存，不写入服务器。

检查命令：

```bash
systemctl is-enabled llama.service vlm.service ai-terminal.service
systemctl is-active  llama.service vlm.service ai-terminal.service
curl http://127.0.0.1:8000/api/device/status
```

实测：开机后约 **22 秒** API 上线；LCD 显示当前 Wi-Fi IP（当前 `192.168.1.165`）与 `READY`。面板也会显示“其他电脑访问”地址。

## 6. 课堂操作

1. 树莓派连接 OpenWrt Wi-Fi；开发板 USB 接树莓派；按需接网线。
2. 打开树莓派电源，等待 LCD 出现 Wi-Fi IP / `READY`（约 20–30 秒）。
3. 你的电脑和其他同学电脑连同一个 Wi-Fi，浏览器打开 `http://192.168.1.165:8000/`。
4. 你的电脑如果走直连网线，也可用 `http://192.168.49.50:8000/`。
5. 按 `docs/答辩演示脚本.md` 演示。

不需要在电脑或树莓派上手动启动任何服务。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 其他电脑打不开 | 确认与 Pi 同一 Wi-Fi；`ping 192.168.1.165`；以面板/LCD 当前地址为准 |
| 你的电脑走网线打不开 | `ping 192.168.49.50`；检查以太网 `192.168.49.11/24`、网关留空 |
| Wi-Fi IP 变了 | 面板“其他电脑访问”/LCD 会更新；建议在 OpenWrt 给 Pi 做 DHCP 静态租约 |
| 页面打开但串口未连接 | 拔插开发板 USB；刷新页面；或 `POST /api/device/reconnect` |
| 服务未启动 | `sudo systemctl restart llama.service vlm.service ai-terminal.service` |
| 需要重新安装自启 | `ROOT=/home/apple/ai-terminal bash scripts/install_services.sh` |

## 8. 可选：树莓派 Wi-Fi 连接

当前已连接 OpenWrt（`wlan0=192.168.1.165`）。如需换网络：

```bash
nmcli device wifi list
nmcli device wifi connect "Wi-Fi 名称" password "密码"
```

eth0 仍保持 `192.168.49.50` 固定地址，直连维护不受影响。换 Wi-Fi 后，面板/LCD 会自动显示新的访问 IP。

## 9. 跨网访问（Cloudflare 临时隧道）

如果同学不在同一个 Wi-Fi，可用 Cloudflare 临时隧道，不需要公网 IP：

```bash
bash scripts/start_tunnel.sh
grep -oE 'https://[a-z0-9-]+\.trycloudflare\.com' ~/ai-terminal/logs/cloudflared.log | tail -1
```

- 公网请求需要 Basic 密码，凭据在 `~/.ai_terminal_access`（不入 Git）。
- 只对公网请求要求密码；局域网 `192.168.1.165:8000` 保持免密。
- 临时链接无可用性保证；停止用 `bash scripts/stop_tunnel.sh`。
- 详细说明见 `docs/公网访问.md`。
