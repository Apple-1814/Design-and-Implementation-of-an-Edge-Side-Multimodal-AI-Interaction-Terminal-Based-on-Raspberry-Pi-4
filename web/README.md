# web —— 前端聊天界面（M4）

计划：**Vue 3 + Vite + Tailwind**，在 PC 上构建，`dist/` 由树莓派 FastAPI 静态托管；Pi 端不装 Node。

## 页面

| 页面 | 内容 |
|---|---|
| `/chat` | 聊天主界面：流式 Markdown、代码高亮、图片上传、停止/重试 |
| `/sessions` | 会话历史 |
| `/scripts` | 脚本/设备面板：LED、LCD、ADC、PWM |
| `/settings` | 模型、串口、后端地址 |

## 状态矩阵

加载、空、错误、离线、串口断开、模型加载中、烧录中。

## 约定

- 与后端通过 HTTP + SSE 通信。
- 图片上传走后端 VLM；不在前端直接调用模型。
- 深色科技风，正文对比度 ≥4.5:1。
